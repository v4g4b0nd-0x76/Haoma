Haoma's type is inspired by manuscripts: an ornamental headpiece under every title, eight-pointed star bullets, an optional drop cap, and couplets set in two hemistichs. Persian couplets use a real Nastaliq face, the hand of the Shahnameh manuscripts.

## A Persian couplet

{{< verse lang="fa" source="Ferdowsi, Shahnameh (opening)" >}}
به نام خداوند جان و خرد | کزین برتر اندیشه برنگذرد
{{< /verse >}}

## An English couplet

{{< verse source="Written for this guide" >}}

{{< /verse >}}

## Lists use the star marker

- The headpiece is added automatically under every page title.
- Add `dropcap: true` to the front matter for a large first letter (English pages).
- Use the verse shortcode for poetry: one couplet per line, hemistichs separated by a vertical bar.
