# Contributing

Corrections are welcome. Four easy ways:

1. On any page, click **Edit this page on GitHub** and propose the change as a pull request.
2. Click **Report a correction** to open a prefilled issue.
3. **Web editor (no install):** open [/tools/](https://v4g4b0nd-0x76.github.io/Haoma/tools/) → **Open editor** (guide: [/editor/](https://v4g4b0nd-0x76.github.io/Haoma/editor/)).
4. **Desktop binary or Python:** download an `editor-v…` asset from [Releases](https://github.com/v4g4b0nd-0x76/Haoma/releases), place it next to `hugo.toml`, and run it — or `python tools/editor.py` (needs Hugo Extended + git). Use **Publish & PR**.

Rules: every factual claim needs a source; set the evidence grade; use only public-domain or open-licensed media; text is CC BY-SA, code is MIT.
